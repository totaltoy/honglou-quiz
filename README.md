# 太虚幻境 · 身份册

「穿越到红楼梦，你会是谁？」——纯前端 H5 性格测试小程序，面向 C 端传播。

- **玩法**：12 道红楼情境题（改编自结诗社、葬花、宝玉挨打、螃蟹宴等名场面）→ 六维人格（才情 / 世故 / 叛逆 / 果决 / 豁达 / 细腻）→ 匹配 16 个红楼角色（黛玉、宝钗、宝玉、凤姐、探春、湘云、妙玉、晴雯、李纨、袭人、刘姥姥、香菱、惜春、薛蟠、平儿、尤三姐）。
- **结果**：判词 + 现代话解读 + 人格标签 + 六维雷达图 + 匹配度 + 影子人格（第二名）+ 知音，可一键生成 750×1334 身份卡图片、复制邀请文案。
- **传播闭环（零后端）**：邀请文案附带专属链接 `?from=<角色id>`；好友点开 → 封面显示「XX邀你同入幻境」→ 测完结果页多一块「缘分」卡：同款触发"同款认亲"，不同款命中 13 组考据关系彩蛋（黛玉×宝玉木石前盟、凤姐×平儿千斤双臂、晴雯×宝玉撕扇之谊等）或"园中同游"兜底——每个人的链接都带自己的角色，链式接力传播。
- **纯静态、零依赖、无后端**：所有数据与计分都在浏览器本地完成。

## 本地运行

```bash
cd honglou-quiz
python3 -m http.server 4173
# 打开 http://localhost:4173 （建议用浏览器手机模拟或真机访问）
```

> 直接双击 `index.html`（file:// 协议）也能运行，但部分安卓微信内核对 file:// 支持差，正式使用请走 HTTP。

## 上线（对 C 端开放）

把整个目录扔到任意静态托管即可，无需构建：

| 方式 | 一键命令 / 步骤 |
| --- | --- |
| Vercel（推荐） | `npx vercel --prod`（首次会弹浏览器登录），得 `*.vercel.app` 域名 |
| Netlify | `npx netlify-cli deploy --dir . --prod`（首次弹浏览器登录） |
| GitHub Pages | 新建仓库 → 上传本目录 → Settings → Pages 开启（或装 gh CLI 后 `gh repo create` + `gh pages`） |
| 自己的服务器 | nginx `root` 指向本目录即可 |

**分享缩略图已就位**：`assets/og-image.jpg`（1200×630，74KB）已接入 og:image / twitter:card，favicon 为内联印章 SVG，无需额外配置。注意：**微信内置浏览器**不走标准 og 协议，要在微信聊天里显示自定义卡片标题/缩略图，需公众号 JS-SDK 签名接口或已备案域名 + 微信认证；普通浏览器和多数社交平台会直接读取 og 标签。

## 移植微信小程序

`js/data.js` 与框架无关（全局变量 + 纯函数），可原样拷入小程序工程：

1. 页面结构照 `index.html` 三屏（封面 / 答题 / 结果）拆成 3 个 page；
2. `js/app.js` 中的 DOM 操作换成 `setData`，雷达图改用 canvas 2d 接口（逻辑同 `drawRadar`）；
3. 身份卡生成用小程序侧 `wx.canvasToTempFilePath`，绘制参数照抄 `buildCardCanvas`；
4. 计分直接调用 `data.js` 的 `scoreAnswers(answers)`，返回值含 `top / shadow / topPct / u`。

## 自定义内容

所有内容集中在 `js/data.js`：

- **加题 / 改题**：`QUESTIONS` 数组，每题 4 个选项，`score` 里给六维加分（每维满分为所有题该维最高分之和，自动归一化到 0~5）；
- **加角色**：`CHARACTERS` 数组，`vector` 是角色在六维上的原型（0~5）；
- **调判词 / 文案**：`quote / tagline / desc / tags / confidant` 字段直接改。

改完跑一下区分度自测（Node 即可，无需浏览器）：

```bash
node scripts/test-scoring.js
```

它会校验：十一类典型人格落在预期角色、全部 4^12 种答题组合不报错、16 个角色都能被选为第一名（Top1 覆盖 16/16）。新增角色时务必跑一遍：若某角色永远排不到第一，微调其 `vector`（通常是某两维被题目组合"锁死"，如才情与世故互斥）；若老角色被挤掉，同样微调新角色向量让出位置。
